# Trabalho de Conclusão de Curso (TCC) MBA-Usp-Esalq em Engenharia de Software


## Repositório de Scripts do TCC MBA em Engenharia de Software Usp Esalq


- Script 1: 01_simulacao_roadmap_devops.py
Objetivo: Executa o motor de Monte Carlo (5.000 iterações), calcula as distribuições Beta-PERT, os incidentes via Processo de Poisson e aplica as fórmulas de equivalência analítica para alimentar as Tabelas 3 e 4 do TCC.

- Script 2: 02_analise_sensibilidade.py
Objetivo: Simula os testes de estresse sobre a Fase 3 (Cenário Conservador com +50% de carga, Cenário Moderado e Cenário Otimista com -20% de carga), gerando a Tabela 5 da Análise de Sensibilidade.

- Script 3: 03_gerar_planilha_graficos_excel.py
Objetivo: Consolida os resultados gerenciais em formato .xlsx estruturado com formatação condicional e constrói automaticamente os dois gráficos combinados editáveis para o TCC.
